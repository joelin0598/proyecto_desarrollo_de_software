## 🔄 FLUJOS IMPLEMENTADOS

### Flujo 1: Paciente con Cita Programada
┌─ Selecciona "Con Cita"
├─ Ingresa ID de cita
├─ Busca cita pagada
├─¿Existe? ─→ SÍ: Carga datos → Salta a VITALS
│           NO: Continúa normal → PERSONAL → EMERGENCY → INSURANCE → VITALS
└─ Guarda triaje

### Flujo 2: Paciente Sin Cita (Encontrado en BD)
┌─ Selecciona "Sin Cita"
├─ Ingresa DPI (13 dígitos)
├─ Busca paciente en BD
├─¿Existe? ─→ SÍ: Precarga DATOS (deshabilitados)
│                ├─ Muestra datos verificados en PERSONAL
│                ├─ Salta a INSURANCE
│                └─ Ingresa VITALS → Guarda
│           NO: Va a PERSONAL → EMERGENCY → INSURANCE → VITALS → Guarda
└─ Fin

### Flujo 3: Paciente Sin Cita (Nuevo)
┌─ Selecciona "Sin Cita"
├─ Ingresa DPI (13 dígitos)
├─ Busca paciente en BD
├─ No encontrado
├─ Abre PERSONAL
├─ Usuario ingresa:
│  ├─ Nombre completo
│  ├─ DPI
│  ├─ Fecha nacimiento
│  ├─ Género
│  ├─ Teléfono
│  ├─ Email
│  └─ Dirección
├─ Continúa EMERGENCY
│  ├─ Nombre contacto
│  └─ Teléfono contacto
├─ Continúa INSURANCE
│  └─ Modalidad de pago (Seguro/Tarjeta)
├─ Continúa VITALS
│  ├─ Presión (Sistólica/Diastólica)
│  ├─ Frecuencia cardíaca
│  ├─ Temperatura
│  ├─ Saturación O2
│  ├─ Peso
│  └─ Talla
└─ Guarda triaje (nuevo paciente)
