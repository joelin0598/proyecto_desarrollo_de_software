## 🎯 ELEMENTOS INTERACTIVOS

### Botones Principales
```
[Iniciar Sesión]    → Redirige a /login
[Registrarse]       → Redirige a /register
[Ver Servicios]     → Permanece en /
[Acceder ►]         → Redirige a /login (si no está autenticado)
[Cerrar Sesión]     → Logout y regresa a /
```

### Navegación por Rol
```
ADMIN               → /admin (Dashboard)
USER                → /user (Portal)
NO AUTENTICADO      → / (Landing)
```

### Colores del Tema
```
Primario:       🔵 Azul (#1D4ED8)
Fondo:          ⚪ Blanco (#FFFFFF)
Texto:          ⚫ Gris oscuro (#1F2937)
Éxito:          🟢 Verde (#10B981)
Error:          🔴 Rojo (#EF4444)
```
