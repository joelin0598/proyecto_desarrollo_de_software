┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎯 VALIDACIÓN DE PAGO (SIMULADA)                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  💳 PAGO CON TARJETA:                                                       │
│  ─────────────────────                                                      │
│  SI numeroTarjeta.endsWith("0000")                                          │
│    → ❌ RECHAZADA (simulación de saldo insuficiente)                       │
│    → estado_administrativo = 'PAGO_PENDIENTE'                              │
│                                                                              │
│  SI NO (termina en otro número)                                             │
│    → ✅ APROBADA                                                            │
│    → estado_administrativo = 'PAGO_VALIDADO'                               │
│                                                                              │
│  Ejemplos:                                                                  │
│    • 4111111111111111 → ✅ APROBADA                                        │
│    • 4111111111110000 → ❌ RECHAZADA                                       │
│    • 5500005500005500 → ✅ APROBADA                                        │
│                                                                              │
│  🏥 PAGO CON SEGURO:                                                        │
│  ──────────────────                                                         │
│  SI póliza.startsWith("X") OR póliza.contains("RECHAZADA")                │
│    → ❌ RECHAZADA (simulación de póliza no vigente)                       │
│    → estado_administrativo = 'PAGO_PENDIENTE'                              │
│                                                                              │
│  SI NO                                                                      │
│    → ✅ APROBADA                                                            │
│    → estado_administrativo = 'PAGO_VALIDADO'                               │
│                                                                              │
│  Ejemplos:                                                                  │
│    • POL2024001234     → ✅ APROBADA                                       │
│    • XPOL2024001234    → ❌ RECHAZADA                                      │
│    • POL-RECHAZADA     → ❌ RECHAZADA                                      │
│                                                                              │

├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  CU 2.0: TRIAGE (Urgencia)                                                  │
│  ───────────────────────────                                                │
│  Paciente llega → Registra signos vitales → Asigna prioridad               │
│  ✗ NO crea cita automáticamente                                             │
│                                                                              │
│  ↓                                                                           │
│                                                                              │
│  CU 04: APPOINTMENT SCHEDULING (Agendar cita)                              │
│  ──────────────────────────────────────────────                            │
│  POST /api/appointments                                                     │
│  ├─ Validar pago (tarjeta o seguro)                                        │
│  ├─ SI aprobado → estado_administrativo = PAGO_VALIDADO ✅                │
│  └─ SI rechazado → estado_administrativo = PAGO_PENDIENTE ❌              │
│                                                                              │
│  ↓                                                                           │
│                                                                              │
│  CU 06: APPOINTMENT ATTENTION (Atender cita) ← TÚ ESTÁS AQUÍ               │
│  ────────────────────────────────────────────                              │
│  /doctor/appointments/attention                                             │
│                                                                              │
│  GET /api/appointments/attention/queue                                      │
│  └─ Muestra SOLO citas con:                                                │
│     • estado_cita = 'PROGRAMADA'                                           │
│     • estado_administrativo = 'PAGO_VALIDADO'                              │
│                                                                              │
│  Doctor hace clic en "Iniciar atención"                                     │
│  └─ POST /api/appointments/attention/open                                  │
│     └─ estado_cita pasa a EN_CURSO                                         │
│        └─ Desaparece de la cola                                            │
│           └─ Aparece en "Atención en curso"                                │
│                                                                              │
│  Doctor registra evaluación y diagnóstico                                   │
│  └─ PATCH /api/appointments/attention/{id}/close                           │
│     └─ estado_cita pasa a ATENDIDA                                         │
│        └─ Se guarda: evaluación física, diagnóstico, etc.                 │
│           └─ Desaparece completamente de la cola                           │
│                                                                              │
